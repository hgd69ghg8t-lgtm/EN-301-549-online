C.9.7 User preferences for web pages

Type of assessment: Inspection

Requirement: The ICT is, or includes, a web page.

Preconditions:

Procedure:

  1. Check that the web page does not block the user agent's mode(s) of operation that present the web page according to user preference settings.
  2. Check that the web page does not explicitly override user preferences for documented platform accessibility features in these modes of operation.
  3. Check each case where a user preference is explicitly overridden to identify whether meeting the user preference would fundamentally alter the information or function of the web page.

Result:

  • Pass: Check 1 is true AND (check 2 Or check 3 are true)
  • Fail: Check 1 is false OR (check 2 is false AND check 3 is false)
  • Not applicable: If any requirement precondition is false (Do not need to meet or test.)
