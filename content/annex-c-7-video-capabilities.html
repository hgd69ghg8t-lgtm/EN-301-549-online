C.7.1.2 Subtitle synchronization

C.7.1.2 Subtitle synchronization
Type of assessmentMeasurement
Requirement
Preconditions
  1. ICT displays video with synchronized audio.
  2. The ICT has a mechanism to display subtitles.
  3. Subtitles are available with timecodes.
  4. The time s identified by the start timecode of a subtitle can be determined.
  5. The time t when a subtitle appears can be determined.
Procedure

For a minimum of 10 subtitles:

  1. Note the point in time t when a subtitle is supposed to be presented.
  2. Note the point in time s when a subtitle is actually presented.
  3. Note the Values m = (t - s) for each of the 10 instances.
  4. Check that the Average(AbsoluteValue(mValues)) ≤ 100 ms.
Result

Pass: Check 4 is true

Fail: Check 4 is false

Not applicable: If any requirement precondition is false (Do not need to meet or test.)

C.7.2 Audio description technology

C.7.2.1 Audio description playback

C.7.2.1 Audio description playback
Type of assessmentInspection
Requirement
Preconditions
  1. The ICT displays video with synchronized audio.
Test Assumptions
  1. A video source that includes audio description is available.
Procedure
  1. Check that there is an explicit and separate mechanism for audio description.
  2. Check that there is a mechanism to select and play the audio description to the default audio channel.
  3. Check that the ICT enables the user to select and play one of several audio tracks.
Result

Pass: Checks 1 and 2 are true or 1 is false and 3 is true

Fail: Check 1 is true and 2 is false or 1 is false and 3 is false

Not applicable: If any requirement precondition is false (Do not need to meet or test.)

Test approach cannot be used: If any Test Assumption is not true. Need to use a different test approach.
