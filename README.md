# EN 301 549 Online

An unofficial HTML edition of **ETSI EN 301 549 V4.1.0** — *Accessibility
requirements for ICT products and services* — that makes the standard
easier to read, search and link to than the source PDF.

It reproduces the standard as one accessible web page per clause and
annex, with a persistent contents sidebar, full-text search, and stable
direct links to individual clauses and requirements.

## Official source

This edition is **unofficial**. ETSI, CEN and CENELEC have not endorsed
it. The official ETSI PDF is the authoritative version: where this HTML
edition differs from that PDF in any way, the PDF governs. The version
reproduced here is a **final draft under approval, not yet a published
standard**.

Permission to reproduce and publish the ETSI material has **not yet been
obtained**, so this project is **not cleared for public publication**. See
[`LICENSES.md`](LICENSES.md) for the licensing, copyright and
publication-readiness details.
