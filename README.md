# EN 301 549 Online

An accessible, WCAG 2.2 AA-conformant website version of the EN 301 549 standard, styled with the [NZ Government Design System](https://design-system-alpha.digital.govt.nz/) and structured similarly to [legislation.govt.nz](https://www.legislation.govt.nz/act/public/1991/69/en/latest/).

## Project structure

```
source/   Source PDF(s) go here
docs/     Generated accessible HTML site (published via GitHub Pages)
```

## Adding the source PDF

Drop the PDF into the `source/` folder (see `source/README.md` for details).

## Hosting

This site is published for free via GitHub Pages, serving from the `docs/` folder on the `main` branch. Once merged, enable it under **Settings → Pages → Source: Deploy from a branch → main /docs**.
